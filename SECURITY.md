# Security Policy

## Supported versions

This repository is a deprecated source showcase. No deployed service or released version is currently supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not disclose suspected vulnerabilities, credentials, or private infrastructure details in a public issue.

Include the affected path, impact, reproduction details, and any recommended mitigation. Reports are reviewed on a best-effort basis because the original services are offline.

## Credentials

Never commit access tokens, keys, passwords, connection strings, signing material, or production environment files. Supply authorized environment configuration outside tracked Unreal project files.
